# Pixwith.ai Account Creator Bot 🤖

نظام أتمتة متكامل لإنشاء حسابات تلقائية على منصة **Pixwith.ai** باستخدام بريد إلكتروني مؤقت.

## 🚀 المميزات الجديدة
- **المحرك:** استخدام `puppeteer-core` لتقليل الحجم وتحسين الأداء.
- **واجهة CLI:** إمكانية تشغيل البوت مباشرة من سطر الأوامر.
- **دعم GitHub Actions:** إمكانية التشغيل السحابي مجاناً وبثبات.
- **تلقائي:** البحث عن مسار المتصفح (Chrome/Chromium) تلقائياً.

## 🛠️ المتطلبات التقنية
- **Node.js:** الإصدار 18 أو أحدث.
- **متصفح Chrome أو Chromium:** يجب أن يكون مثبتاً على جهازك.

## 📥 التثبيت والتشغيل المحلي

1. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

2. **التشغيل عبر واجهة الويب (Dashboard):**
   ```bash
   npm run dev
   ```
   افتح: `http://localhost:3000`

3. **التشغيل عبر سطر الأوامر (CLI):**
   ```bash
   npm run bot -- --referral "رابط_الإحالة_الخاص_بك" --count 10
   ```

## ⚙️ التشغيل عبر GitHub Actions

1. ارفع الكود إلى مستودع (Repository) خاص بك على GitHub.
2. اذهب إلى تبويب **Actions**.
3. اختر **Pixwith Account Creator Bot**.
4. اضغط على **Run workflow**.
5. أدخل رابط الإحالة وعدد الحسابات (مثلاً 10) ثم ابدأ التشغيل.
6. بعد الانتهاء، ستجد ملف `accounts.json` قد تم تحديثه في المستودع، أو يمكنك تحميله من الـ Artifacts.

## 📂 هيكل المجلدات المحدث
- `src/cli.ts`: واجهة سطر الأوامر للتشغيل السريع.
- `src/automation/PixwithAutomation.ts`: المحرك المعتمد على Puppeteer.
- `.github/workflows/bot.yml`: إعدادات التشغيل الآلي على GitHub.

## ⚠️ ملاحظة بخصوص Vercel
تم تحويل المحرك إلى Puppeteer، ولكن لا تزال Vercel غير مناسبة للعمليات الطويلة. يفضل استخدام **GitHub Actions** أو **التشغيل المحلي** كبدائل أفضل.
