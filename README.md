# Pixwith.ai Account Creator Bot 🤖

نظام أتمتة متكامل لإنشاء حسابات تلقائية على منصة **Pixwith.ai** باستخدام بريد إلكتروني مؤقت ودعم روابط الإحالة والبروكسي.

## 🚀 المميزات
- **أتمتة كاملة:** تسجيل حسابات بشكل مستمر دون تدخل بشري.
- **واجهة تحكم ويب (Dashboard):** متابعة العمليات، السجلات الحية (Live Logs)، والتحكم بالبوت (بدء/إيقاف).
- **دعم البريد المؤقت:** تكامل تام مع API موقع `Mail.tm`.
- **نظام البروكسي:** دعم قائمة بروكسيات (Round-robin) لتجنب الحظر.
- **حفظ تلقائي:** تخزين بيانات الحسابات المنشأة في ملف `data/accounts.json`.
- **هيكلية نظيفة:** مبني باستخدام TypeScript و OOP.

## 🛠️ المتطلبات التقنية
- **Node.js:** الإصدار 18 أو أحدث.
- **TypeScript:** للترجمة البرمجية.
- **Playwright:** لمحاكاة المتصفح.

## 📥 التثبيت والتشغيل المحلي

1. **تحميل المشروع:**
   ```bash
   git clone <repository-url>
   cd PixwithAIAccountCreator
   ```

2. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

3. **تثبيت متصفح Chromium (الخاص بـ Playwright):**
   ```bash
   npx playwright install chromium
   ```

4. **بناء المشروع:**
   ```bash
   npm run build
   ```

5. **بدء التشغيل:**
   ```bash
   npm start
   ```
   افتح المتصفح على: `http://localhost:3000`

## 🌐 النشر على Vercel (ملاحظات هامة)

هذا المشروع مصمم ليعمل كـ **سيرفر دائم (Long-running Process)** باستخدام WebSockets و Playwright.

- **القيود:** منصة Vercel تعتمد على بيئة (Serverless Functions) التي لها وقت تنفيذ محدود (Max Timeout) ولا تدعم WebSockets بشكل دائم أو تشغيل Playwright بسهولة دون إعدادات خاصة وثقيلة.
- **التوصية:** يفضل تشغيل هذا البوت على **VPS** (مثل DigitalOcean أو Hetzner) أو استخدامه **محلياً** لضمان استمرارية عمل المتصفح والسجلات الحية.

إذا كنت ترغب في المحاولة على Vercel، تم إضافة ملف `vercel.json` لإعداد نقطة النهاية، ولكن قد تحتاج لاستخدام متصفح سحابي خارجي (مثل Browserless.io).

## 📂 هيكل المجلدات
- `src/automation`: محرك Playwright الخاص بالتسجيل.
- `src/services`: خدمات البريد المؤقت.
- `src/server`: سيرفر Express و Socket.io.
- `src/utils`: إدارة البروكسي والسجلات.
- `public`: ملفات واجهة المستخدم الرسومية.
- `data`: ملفات حفظ البيانات (Log & Accounts).
